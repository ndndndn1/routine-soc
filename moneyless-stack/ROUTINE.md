# ROUTINE

This directory is driven by `Research & Build Routine v6`. The routine
lives in the session instructions (not checked in verbatim).

## v6 contract

- Hypothesis: 화폐의 매개 기능 잉여화 — given (a) physically reliable
  production, (b) recoverable surplus absorbable by non-essential
  wants, and (c) measurement-grounded resource priority, money becomes
  surplus.
- Papers are *parts*, not direct support. Each adopted paper must
  reduce to a node, link, or function in the moneyless stack.

## Combos (v6)

- **A — physics-input**: per-node calibrated health/lifetime estimate
  with uncertainty. Output is a consensus input.
- **B — cost-surplus**: marginal-cost reduction (repair, OSH,
  distributed manufacturing) and the absorption of surplus into
  non-essential wants.
- **C — priority-from-measurement**: physical measurement (exergy,
  LCA, DPP) → resource priority ordering.
- **D — near-sensor judgment**: keep judgment local — TinyML, TEE,
  remote attestation — so the link upward carries a decision, not a
  stream.

## Adoption rule (v6)

- 2+ keyword matches AND ≥ 2.5 summed score (full = 1.0, partial = 0.5).
- DOI / arXiv ID dedup within and across combos.
- Search window: last 2 years.
- 신뢰도 낮으면 "근거 부족" 명시. 추측 금지.

## Sociology rule

- 사회학 논문은 ROADMAP.md만 갱신. Code or link changes are not triggered
  by a sociology paper.

## Default deny

All inter-node communication is **closed by default**. A link opens
only after a physical basis is justified in `PHYSICAL_LINKS.md` with
≥ 1 engineering reference.

## Layer stack (v4 carry-over, still in use)

- L1 Reliability Physics   — physically reliable production substrate
- L2 Entropy Buffer        — allocation of surplus to non-essential wants
- L3 Physical Consensus    — distributed consensus directly off measurements

## Run cadence

- Multiple combos may be completed in a single run if the task is a
  v6 bootstrap (4 combos to ramp up).
- Steady-state: one task per run (search OR code OR link OR
  ROADMAP/synthesis).
